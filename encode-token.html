Actions token encoder

This runs entirely in your browser — nothing is sent anywhere. Paste your fine-grained GitHub token (the one scoped to only "Actions: Read and write" on this repo — never paste a token with Contents access into any web page). Copy the encoded result into GH_ACTIONS_TOKEN_B64 in index.html. Encoding it this way stops GitHub's secret scanner from auto-revoking it when you push — it does not add real secrecy, since the page decodes and uses it in plain text. Delete this file from the repo afterward if you like.
